3. Realiza un script que solicite dos números al usuario y los compare, mostrando cuál es mayor, o si son iguales.

````
#!/bin/bash

read -p "Introduce el primer numero: " numero1
read -p "Introduce el segundo numero: " numero2

if [ $numero1 -eq $numero2 ]
then
        echo "$numero1 es igual que $numero2"

elif [ $numero1 -gt $numero2 ]
then
        echo "$numero1 es mayor que $numero2"

elif [ $numero1 -lt $numero2 ]
then
        echo "$numero1 es menor que $numero2"
fi

````

8. Crea un script que compruebe el espacio libre en disco. Si el espacio es inferior al 10%, muestra un mensaje de advertencia.

````

#!/bin/bash

archivo_memoria=memoria

df --total | grep -v Use% |awk '{print $5}' > "$archivo_memoria"

for linea in  $(cat "$archivo_memoria")
do
        linea=${linea%\%}

        if [ "$linea" -gt 90 ]
        then
                echo "ADVERTENCIA: poco espacio libre "
        else
                echo "Todo bien"
        fi
done

rm "$archivo_memoria"


````

10. Haz un script que solicite al usuario su edad y determine si es menor, adulto o mayor de edad, según un umbral predefinido (por ejemplo, menor de 18, entre 18 y 65, y mayor de 65).

````

#!/bin/bash

read -p "Introduce tu edad: " edad

if [ $edad -lt 18 ]
then
        echo "Eres menor de edad"
elif [ $edad -ge 18 ] && [ $edad -lt 65 ]
then
        echo "Eres mayor de edad"

elif [ $edad -ge 65 ]
then
        echo "Eres adulto"

fi
````
