3. Realiza un script que solicite dos números al usuario y los compare, mostrando cuál es mayor, o si son iguales.

````
#!/bin/bash

read -p "Introduce el primer numero: " numero1
read -p "Introduce el segundo numero: " numero2

if [ $numero1 -eq $numero2 ]
then
        echo "$numero1 es igual que $numero2"

elif [ $numero1 -gt $numero2 ]
then
        echo "$numero1 es mayor que $numero2"

elif [ $numero1 -lt $numero2 ]
then
        echo "$numero1 es menor que $numero2"
fi

````

5. Crea un script que compruebe si un directorio (que solicitará por teclado al usuario) existe y si tiene permisos de escritura. Si el directorio no existe, crea uno nuevo.
````
#!/bin/bash

read -p "Introduce introduce un directorio: " directorio

if [ -d $directorio ] && [ -w $directorio ]
then
        echo "$directorio existe y tiene permisos de escritura"

else
        mkdir "$directorio"
        chmod +w "$directorio"
        echo "Se ha creado $directorio"

fi


````
