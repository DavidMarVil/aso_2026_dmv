1. Calculadora básica
Crea un script que funcione como una calculadora de operaciones básicas.

Debe recibir como parámetros:

Primer número
Operación (+, -, *, /)
Segundo número Si no se pasan parámetros, debe solicitar los valores al usuario.
Debe manejar errores, como división por 0.

````
#!/bin/bash

if [ ! $# -eq 3 ]
then
        echo "Introduce todos los parametros"

elif [ "$2" = "+" ]
then
        suma=$(("$1" + "$3"))
        echo "$suma"

elif [ "$2" = "-" ]
then
        resta=$(("$1" - "$3"))
        echo "$resta"

elif [ "$2" = "*" ]
then
        multiplicacion=$(("$1" "*" "$3"))
        echo "$multiplicacion"

elif [ "$2" = "/" ]
then
        if [ "$1" = 0 ] || [ "$3" = 0 ]
        then
                echo "No se puede dividir entre cero"
        else
                division=$(( "$1" / "$3" ))
                echo "$division"
        fi
fi
````
