2. Validador de direcciones IP
Crea un script que verifique si una dirección IP es válida.

- Debe recibir la dirección IP como parámetro.
- Si no se pasa, debe pedirla al usuario.
- Usa grep para validar el formato X.X.X.X, donde X es un número que tiene entre 1 y 3 dígitos.

````

#!/bin/bash

if [ $# -ne 1 ]
then
        read -p "Introduce una ip: " ip
else
        ip="$1"

fi

if echo "$ip" | grep -Eq '^([0-9]{1,3}\.){3}[0-9]{1,3}$'
then
        echo "La IP $ip es valida"
else
        echo "La IP $ip no es valida"
fi

````





3. Contador de archivos por tipo
Crea un script que cuente archivos de distintos tipos en un directorio.

- Debe recibir el directorio como parámetro (si no se pasara el parámetro lo solicitará por teclado).
- Mostrará cuántos archivos hay de cada extensión (.txt, .sh, .log, etc.).
Usa find y grep para procesar los datos.

````
#!/bin/bash

txt_cuenta=0
sh_cuenta=0
log_cuenta=0

if [ "$#" -ne 1 ]
then

        read -p "Introduce un directorio: " directorio

else

directorio="$1"

fi

if [ -d "$directorio" ]
then
        for linea in "$directorio"/*.txt
         do
                if [ -f "$linea" ]
                then
                        (("txt_cuenta"++))
                fi
        done

                for linea in "$directorio"/*.sh
                do
                        if [ -f "$linea" ]
                        then
                                (("sh_cuenta"++))
                        fi
                done

                for linea in "$directorio"/*.log
                do
                        if [ -f "$linea" ]
                        then
                                (("log_cuenta"++))
                        fi
                done

                echo "$txt_cuenta archivos .txt"
                echo "$sh_cuenta archivos .sh"
                echo "$log_cuenta archivos .log"
        fi
     
````

5. Backup de un directorio
Descripción:

Crea un script que realice una copia de seguridad de un directorio.

- Debe recibir el directorio origen y el directorio destino como parámetros.
- Si no se pasan, debe solicitarlos.
- Usa el comando tar para generar el backup con la fecha actual en el nombre.
  
````

#!/bin/bash


fecha=$(date +%Y%m%d)

if [ "$#" -ne 2 ]
then
        read -p "Introduce el directorio destino: " destino
        read -p "Introduce el directorio del que se realizara la copia: " copia
else
        destino="$1"
        copia="$2"
fi


if [ -d "$destino" ] && [ -d "$copia" ]
then
                directorio_comprimido="$destino"/"$fecha".tar.gz

                tar -zcvf "$directorio_comprimido" "$copia" > /dev/null 2>&1
                echo "Backup creado: $directorio_comprimido"
fi


````


6. Conversor de temperatura (Celsius ⇄ Fahrenheit)
Crea un script que convierta una temperatura entre Celsius y Fahrenheit.

- Debe recibir la temperatura y la unidad como parámetros (C o F).
- Si no se pasan, debe solicitarlos al usuario.

````

#!/bin/bash


if [ $# -ne 2 ]
then

        read -p "Introduce la tempertatura: " temperatura
        read -p "Intruduce la unidad: " unidad
else

        temperatura="$1"
        unidad="$2"

fi

if [ "$unidad" == "C" ]
then
        operacion=$((("$temperatura"*9/5)+32))
        echo "$temperaturaº$unidad = $operacionºF"

elif [ "$unidad" == "F" ]
then
        operacion=$((("$temperatura"-32)*5/9))
        echo "$temperaturaº$unidad = $operacionºC"

fi


````

7.  Script para comparar dos archivos
Crea un script que compare dos archivos y muestre las diferencias.

Debe recibir los dos archivos como parámetros.
Si no se pasan, debe solicitarlos.
Usa diff para comparar y mostrar diferencias resaltada

````

#!/bin/bash

if [ "$#" -ne 2 ]
then
        read -p "Introduce el primer archivo: " archivo1
        read -p "Introduce el segundo archivo: " archivo2
else
        archivo1="$1"
        archivo2="$2"

fi

if [ -f "$archivo1" ] && [ -f "$archivo2" ]
then
        comparacion=$(diff -y "$archivo1" "$archivo2")
        echo "$comparacion"
else
        echo "Algunos de los dos directorios no existen"
fi

````
