1. Crea un script que muestre un menú con opciones para sumar, restar, multiplicar y dividir dos números. Debe pedir primero un operando, luego el otro y finalmente la operación a realizar. Usa case para realizar la operación seleccionada por el usuario.

````

#!/bin/bash

echo "+: suma"
echo "-: resta "
echo "*: multiplicar"
echo "/: dividir"


read -p "Introduce un numero: " numero1
read -p "Introduce el segundo numero: " numero2
read -p "Introduce que operacion quieres realizar: " simbolo

case $simbolo in
        \+)
                operacion=$(($numero1+$numero2))
                echo "$operacion"
        ;;

        \-)
                operacion=$(($numero1 - $numero2))
                echo "$operacion"
        ;;

        \*)
                operacion=$(($numero1 * $numero2))
                echo "$operacion"
        ;;
        \/)
                operacion=$(($numero1 / $numero2))
                echo "$operacion"
        ;;
esac

````

6. Haz un script que convierta una temperatura ingresada por el usuario de Celsius a Fahrenheit, de Fahrenheit a Celsius o de Celsius a Kelvin, usando case para seleccionar la conversión deseada.

La fórmula para realizar las conversiones es:

- Grados Fahrenheit = Grados Celsius * 1.8 + 32
- Grados Celsius = ( Grados Fahrenheit - 32) / 1.8
  
````

#!/bin/bash

read -p "Introduce la unidad: " unidad

case "$unidad" in
        F)
                read -p "Introduce la temperatura: " temperatura
                read -p "Introduce la unidad de la conversion: " unidad_conversion

                if [ "$unidad_conversion" == C ]
                then
                        conversion=$((($temperatura - 32)/1,8))
                        echo "$conversionºC"

                elif [  "$unidad_conversion" == K ]
                then
                        conversion=$((($temperatura - 32)/1,8 + 273,15))
                        echo "$conversionºK"
                fi
        ;;

        C)
                read -p "Introduce la temperatura: " temperatura
                read -p "Introduce la unidad de la conversion: " unidad_conversion

                if [ "$unidad_conversion" == F ]
                then
                        conversion=$(($temperatura * 1,8 + 32))
                        echo "$conversionºF"

                elif [  "$unidad_conversion" == K ]
                then
                        conversion=$(($temperatura + 273,15))
                        echo "$conversionºK"

                fi
        ;;

        K)
                read -p "Introduce la temperatura: " temperatura
                read -p "Introduce la unidad de la conversion: " unidad_conversion

                if [ "$unidad_conversion" == C ]
                then
                        conversion=$(($temperatura - 273,15))
                        echo "$conversionºC"

                elif [  "$unidad_conversion" == F ]
                then
                        conversion=$((($temperatura-273,15)/1,8 + 32))
                        echo "$conversionºF"

                fi

        ;;

esac

````

8. Desarrolla un script que permita al usuario convertir metros a kilómetros, metros a centímetros, o metros a milímetros, utilizando case para manejar cada opción de conversión.
   
````

read -p "Introduce los metros: " metros

echo "Elige la conversion:"
echo "1. Metros a kilometros"
echo "2. Metros a centimetros"
echo "3. Metros a milimetros"

read -p "Selecciona una opcion: " opcion

case "$opcion" in
    1)
        resultado=$(( $metros / 1000))
        echo "$metros metros son $resultado kilometros"
        ;;
    2)
        resultado=$(($metros * 100))
        echo "$metros metros son $resultado centimetros"
        ;;
    3)
        resultado=$(($metros * 1000))
        echo "$metros metros son $resultado milimetros"
        ;;
    *)
        echo "Opcion incorrecta"
        ;;
esac
````
